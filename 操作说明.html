AWACSMARK 操作说明

AWACSMARK 是一个 DCS World 预警机辅助工具，通过 OCR 识别预警机通报文字，将敌机位置、高度、航向实时显示在雷达覆盖窗上。

1. 快速开始

1.1 前置条件

  1. DCS World 中已配置 Lua 导出脚本，向 127.0.0.1:12345 发送 UDP 飞行数据
  2. 远程 OCR 服务器已启动（默认 x.x.x.x:10386）
  3. Python 3.13+ 环境，已安装依赖

1.2 启动

python main.py

1.3 操作步骤

  1. 点击 信息查看 → 填写参数 → 确认
  2. 点击 开始（按钮变为「停止」）
  3. 雷达窗口上即开始显示敌机/友机标记
  4. 运行中可随时调整显示模式、比例尺、透明度
  5. 点击 停止 结束任务
提示：如果服务器不可达，软件不会卡死——TCP 预检会在 1 秒内快速失败，且 OCR 处理在独立线程中运行，不影响 UI 响应。

4. 雷达显示模式

模式本机位置视图旋转适用场景
中心 (NGAS) 窗口中心 不旋转（正上=北） 态势感知、配合 F10 地图使用
直对 (SA) 窗口底部中央 随航向旋转（正上=机头） 空战格斗、快速判断敌我方位
中心直对 窗口中心 随航向旋转（正上=机头） 兼顾态势和指向

5. 简要模式

点击工具栏 简要 进入无边框全屏雷达模式：

  • 拖动窗口：鼠标左键按住雷达空白区域拖动
  • 调整大小：鼠标移至窗口边缘，出现双向箭头后拖拽
  • 比例尺：底部水平滑块
  • 退出：点击右上角 恢复 按钮
推荐用法：将简要模式窗口放置在游戏画面的角落（类似 Discord 覆盖层），配合 40%–60% 透明度使用，不影响飞行视野。

6. 服务器模式

模式通报来源语言文本示例
传统预警机 (0) 屏幕左上角 BRA 通报 中文 预警机: Springfield1, 方位 314, 距离 110, 高度 3500, hot
传统预警机(英文) (1) 屏幕左上角 BRA 通报 英文 Overlord1-1: Dodge 4, 314 for 110, at altitude 3500, hot
SPS 服务器 (2) 屏幕右侧数据面板 英文 表格格式：呼号、方位、距离、高度、速度、航向
BSC 服务器 (3) 屏幕右侧数据面板 英文 简化表格格式
注意：服务器模式必须与游戏内使用的预警机类型匹配。英文服务器用中文模式会无法解析文本，导致雷达无显示。

7. 读取雷达图

7.1 敌机标记

元素含义
圆点敌机位置（方位和距离来自预警机通报）
数字敌机高度（千英尺或千米，取决于显示单位设置）
箭头杆敌机航向方向
箭头方向 HOT（迎头）：箭头指向本机中心（敌机正朝你飞来）
COLD（追击）：箭头背离本机（敌机正远离你）
FLANK（侧对）：箭头与方位线垂直
颜色淡出新 contact 为亮青色，随时间逐步变为暗蓝并淡出

7.2 友机标记

蓝色圆点 + 高度数字 + 呼号，箭头方向为友机航向。

7.3 本机标记

中心（或底部中央）的金色箭头为本机，箭头方向 = 机头朝向。

8. 常见问题

Q: 雷达图上没有任何敌机显示

  1. 确认已点击 开始（按钮变为「停止」）
  2. 确认 DCS 正在运行并且 Lua 导出正常（UDP 数据流）
  3. 确认服务器模式与游戏内预警机语言一致（中文 → 模式 0，英文 → 模式 1）
  4. 确认截图区域正确覆盖了预警机通报文字
  5. 检查 logs/app.log 查看是否有「OCR 识别到 0 行文本」

Q: 敌机位置/方位不对

  1. 确认靶眼坐标输入正确（与任务编辑器一致）
  2. 确认预警机通报单位选择正确（km 或 nm）

Q: 箭头方向不对，没有指向我

  • HOT（迎头）：箭头应指向本机中心位置
  • COLD（追击）：箭头背离本机
  • 如果方向完全反了，可能是呼号匹配错误——检查设置中的呼号是否与预警机通报中的完全一致

Q: 窗口拖动/调整大小时卡顿

最新版本已修复此问题。如果仍有卡顿，尝试降低窗口大小。

Q: 服务器无法连接

  1. 检查服务器地址和端口是否正确
  2. 使用设置 → 服务器标签页中的「服务器连通测试」
  3. 如果服务器确实不可达，软件不会卡死——网络操作有 1 秒快速失败和独立线程保护

Q: OCR 识别不准确

  1. 调整截图区域，确保正好包围文字，不要包含地图背景
  2. 避免截图区域包含其他 UI 元素（如无线电菜单）
  3. 英文模式下注意文字大小写和空格

9. 日志说明

位置级别用途
控制台INFO仅显示重要事件：OCR 结果、用户操作、网络错误
logs/app.logDEBUG完整记录，含所有截图、OCR 文本、坐标计算细节

日志文件自动轮转：单文件最大 1 MB，保留 3 个备份（app.log.1 等）。排查问题时，查看日志文件可获得完整的事件序列。
